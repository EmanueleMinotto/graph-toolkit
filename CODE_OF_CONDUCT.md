# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussion focused on the work. Report unacceptable behavior privately through the repository's [security advisory form](https://github.com/EmanueleMinotto/graph-toolkit/security/advisories/new) or to the maintainer via their GitHub profile.
